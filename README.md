# Jarvis Helper App

This project is a simple Jarvis-inspired web app that helps people solve everyday life problems. It includes:

- a modern landing page
- a chat-style interface
- quick action suggestions for stress, money, study, and home issues
- a lightweight Node.js backend with JSON responses

## Run locally

```bash
npm install
npm start
```

Then open:

```bash
http://localhost:3000
```

## Project structure

- `server.js` — Express API and static file server
- `public/index.html` — app UI
- `public/styles.css` — styling
- `public/script.js` — frontend logic
